# Public-release approval checklist / فهرست کنترل تأیید انتشار عمومی

**STATUS: BLOCKED PENDING REVIEW — this is a candidate package, not a statement of clearance.**  
**وضعیت: نیازمند تأیید — وجود این بسته به معنی دریافت مجوز انتشار نیست.**

- [ ] Confirm the person/organization authorized to release the data and reports. / مالک یا مسئول مجاز انتشار مشخص شده باشد.
- [ ] Verify written participant consent, ethics/IRB and applicable law for release of questionnaire data. / رضایت شرکت‌کنندگان و مجوز اخلاق پژوهش بررسی شده باشد.
- [ ] Assess re-identification risk, especially combined age, marital status, education, and unusual responses. / خطر بازشناسایی از ترکیب ویژگی‌ها سنجیده شده باشد.
- [ ] Decide whether *any* individual records can lawfully be released. Default here is **aggregate-only**. / انتشار دادهٔ فردی جداگانه مجاز شناخته شود؛ پیش‌فرض فقط دادهٔ تجمیعی است.
- [ ] Validate `fire` and `non` descriptions and sampling/independence. / معنای گروه‌ها و استقلال داده‌ها تأیید شده باشد.
- [ ] Resolve 119/120 cross-group item matches using source forms. / تطابق سؤال‌های ۱۱۹ جفت پاسخ بررسی شود.
- [ ] Verify scoring manuals including reversed items and the 108 arithmetic discrepancies. / نمره‌گذاری و مغایرت‌های جمع خام بررسی شود.
- [ ] Resolve 31 invalid death-anxiety entries in five records. / کدهای نامعتبر اصلاح یا مستند شوند.
- [ ] Confirm authors, attribution, permission for translation, and a publication license; no license is assumed. / نویسندگان و مجوز انتشار و ترجمه مشخص شوند.
- [ ] Verify PDF/DOCX pages and R analysis on the publisher's machine, and check figures against source. / اسناد و اجرای R و نمودارها بررسی شوند.
- [ ] Decide data-use statement, citation, repository release number, archival identifier (if assigned). / متن استفاده، شیوه ارجاع و شناسه انتشار نهایی شود.
- [ ] Publish only `PUBLIC_CANDIDATE/` after approval; never publish `PRIVATE_REVIEW_ONLY/` by copying the review archive. / پس از تأیید فقط بخش عمومی منتشر شود.

**Publication ethics:** The source includes responses to psychological questionnaires, which can reveal sensitive characteristics even without names. Removing directly identifying columns alone is not proof of anonymity. Any disclosure of participant-level responses requires a separate lawful review.

**اخلاق انتشار:** پاسخ‌های پرسشنامه‌های روان‌شناختی می‌توانند حتی بدون نام، اطلاعات حساس ایجاد کنند؛ حذف شماره یا نام به‌تنهایی ناشناس بودن را تضمین نمی‌کند.
