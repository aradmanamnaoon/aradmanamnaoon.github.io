# Research Atlas | File Inventory / فهرست فایل‌های پژوهش

All publicly distributable reports and source code are directly available in the website download library, in addition to the aggregated ZIP.
تمام فایل‌های قابل انتشار، گزارش‌های فارسی و انگلیسی، کدها، جدول‌ها، شکل‌ها و راهنماها در بخش دریافت فایل‌ها به‌صورت مستقل نیز قرار دارند.

**Data integrity:** 240 records, only 86 distinct questionnaire-response profiles, 119/120 corresponding cross-group pairs with identical item responses. Stored totals may not equal raw item sums; reverse scoring is not verified.
**Important:** The R script is provided for reproducibility but has **not** been executed in this environment. No inferential results should be used as independent-sample evidence.
**Privacy:** Original `raw.sav` is not included in this public site. It exists only in the private review bundle pending participant-data sharing authorization.
