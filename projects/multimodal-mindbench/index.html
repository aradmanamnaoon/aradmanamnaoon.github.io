Multimodal MindBench: auditable EEG + behavior research benchmarking

Multimodal MindBench examines whether an EEG+behavior benchmark has defensible input rights, acquisition-time assumptions and subject separation before any model comparison is interpreted.

01 · Context

Research question

EEG signals and stimulus/response logs may use incompatible clocks, incomplete events, or subject overlaps. A useful benchmark needs to expose these problems instead of silently generating accuracy numbers.

02 · Methods

Approach

  • Versioned rights and clock contracts gate ingestion and document every source file with SHA-256 digests.
  • Bounded-memory EEG readers and deterministic event pairing generate warnings for absent or incompatible timestamps.
  • Synthetic cohorts exercise subject-held-out behavioral-only and EEG-only reference models with separate calibration subjects.
  • Compare early-feature fusion and late probability averaging with missing-modality fallbacks and quality-control exports.
  • Render accessible, keyboard-navigable HTML reports without uploading personal EEG data.

03 · Evaluation

Reported results

  • Hosted GitHub Actions completed successfully on the reviewed source commit; jobs cover Python 3.11, Python 3.13, EDF integration and Chromium browser checks.
  • 71 automated tests passed in the pre-push local run with 91.73% measured line coverage.
  • Synthetic-only outputs establish software behavior, not empirical EEG/behavior predictive validity.

04 · Scope

Limitations

No independently rights-verified real EEG+behavior dataset has completed the scientific acceptance gate. Hardware clock synchronization and external clinical validity are unproven. Treat this as non-diagnostic research software, not a released empirical benchmark.
