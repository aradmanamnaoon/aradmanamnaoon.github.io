Constellation: a local-first multi-agent desktop workspace

Constellation is a developing desktop workspace for organizing multi-agent rooms, choosing model providers and running explicitly requested text tasks with attributed results.

01 · Context

Research question

Multi-agent systems can obscure who produced a response, when a provider was contacted and whether a suggested action has user approval. This prototype explores a local-first interface that keeps those boundaries visible.

02 · Methods

Approach

  • Built a Tauri 2/Svelte 5 frontend backed by Rust and local SQLite state for rooms, agents, messages and tasks.
  • Added 200 prompt-only role templates, per-agent model preferences and explicitly selected multi-agent replies.
  • Implemented bounded text-task workflows, provider-specific reply status, explicit user-triggered requests and local evidence retrieval experiments.
  • Prototyped tightly scoped file read/create proposals that require independent native user confirmation; published an unsigned experimental v0.1.2 Windows/Linux desktop preview without claiming production readiness.

03 · Evaluation

Reported results

  • The local role library contains 200 prompt templates; these are not independently validated integrations or autonomous agents.
  • Rooms support selection of up to eight agents and multiple configured text-provider protocol families.
  • The public v0.1.2 GitHub prerelease contains unsigned Windows x64 portable/setup packages and Linux x86_64 AppImage/DEB packages, with checksum and verification notes. macOS and Android binaries are not included.

04 · Scope

Limitations

The GitHub source repository is public and experimental Windows/Linux binaries are downloadable. These are unsigned preview artifacts, not independently production-certified installers. Full cross-platform GUI acceptance, hardened autonomous coding, finished cloud sync and Android or macOS release binaries are not established. Remote provider requests can send explicitly selected text outside the device and may incur charges.
