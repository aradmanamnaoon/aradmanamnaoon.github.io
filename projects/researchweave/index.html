ResearchWeave: a native research workbench with traceable evidence

ResearchWeave brings project records, PDF evidence, datasets, analyses, notebooks and manuscript exports into one native Rust workspace, with local-first defaults and explicit boundaries for optional AI.

01 · Context

Research question

Research sources, datasets, decisions, analysis results and drafts are often distributed across unrelated tools. The design goal is a reviewable workflow where research objects retain provenance and users can reconstruct the origin of an output.

02 · Methods

Approach

  • Implemented a Rust/Slint desktop workbench organized into Home, Sources, Analyze, Synthesize, Automate and Manage.
  • Connected project revisioning and evidence/source identities with a native PDF reader, reference workflows, dataset imports and statistical analysis paths.
  • Added provenance-aware analysis and manuscript workflows with optional provider-configured AI and explicit approval boundaries.
  • Packaged an owner-approved v0.3.0 early-access release for Windows x64, macOS arm64/x64 and Linux x86_64, with a published SHA-256 manifest.

03 · Evaluation

Reported results

  • The GitHub preview-v0.3.0 release provides five OS-specific packages: Windows installer, two macOS DMGs, Linux AppImage and Debian package.
  • Versioned project workflows cover source records, evidence, quantitative and qualitative analysis, writing and local archives; individual feature readiness varies.
  • Release notes explicitly distinguish owner approval and packaging from independent installed-GUI, scientific and full security acceptance.

04 · Scope

Limitations

The v0.3.0 release is owner-approved early access with known incompleteness. Independent full-platform installed-GUI acceptance, scientific validation and all advertised advanced workflows are not established. Live Iranian Liara S3 synchronization and two-device restore are not included or verified. Do not treat this as clinical or safety-critical research software.
